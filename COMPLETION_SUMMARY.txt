## 📋 REST API ENDPOINTS

1. **GET /health**
   - Check if API is running
   - Returns: `{"status": "healthy"}`

2. **GET /api/data**
   - Get all students
   - Returns: List of students with full details

3. **POST /api/data**
   - Add new student
   - Body: `{"name":"...", "email":"...", "course":"..."}`
   - Returns: Created student with ID

4. **DELETE /api/data/:id**
   - Delete student by ID
   - Returns: Success message

5. **Error Handlers**
   - 404: Not found error
   - 500: Server error
